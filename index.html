NeutraScan

Scan. Identify. Control.

A network scanner for Windows environments. Runs in PowerShell with a WPF interface. No installer.

What it does

  • Scans subnets for live hosts, ports, hostnames and MAC addresses
  • Reads OS and logged-in user via WMI on accessible targets
  • Enumerates local admins, shares and privileges on a target
  • Sends popup messages via msg.exe or WinRM
  • Includes ping, traceroute, DNS, port check, Wake-on-LAN
  • Exports results to CSV, HTML or JSON

Requirements

  • Windows 10 or 11
  • Windows PowerShell 5.1 (built in)
  • Administrator rights for full functionality

Download

Grab both files and keep them in the same folder:

  • NeutraScan.bat
  • NeutraScan.ps1

Running it

  1. Double-click NeutraScan.bat
  2. Accept the UAC prompt
  3. Enter a target range and click Start Scan

Notes

  • Deep scan requires admin rights on the target machine
  • WinRM must be enabled on targets for privilege enumeration
  • Only scan networks you own or have written permission to test
